# Hielke Maps Archiv

Inoffizielle Sammlung historischer Minecraft-Java-Versionen von Hielke Maps
und den auf hielkemaps.com gelisteten Community-Maps.

- [Offizielle Maps](hielke-maps-archive-official.md)
- [Community-Maps](hielke-maps-archive-community.md)
- [ZIP-Downloads in den Releases](https://github.com/GammelSami/hielkemaps-archive/releases)
- [Archiv aktualisieren](doku.md)

Je Map gibt es ein Release mit den archivierten ZIP-Snapshots. Die Tabellen
zeigen den neuesten gespeicherten Snapshot je erkannter Minecraft-Version;
weitere Snapshots derselben Version bleiben in den Releases erhalten.
Die Versionsangabe stammt aus `level.dat` und ist keine Zusage zur Kompatibilität.

Quelle und Urheberangaben: [hielkemaps.com](https://hielkemaps.com/).
Dieses Archiv ist kein offizielles Projekt von Hielke. Rechte an den Maps
und Bildern verbleiben bei den jeweiligen Urhebern.
