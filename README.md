# Hielke Maps Community Archive

An independent, community-maintained archive of Minecraft Java maps created
by Hielke and the community creators featured on hielkemaps.com.
This project is not affiliated with or endorsed by Hielke.

- [Maps by Hielke](hielke-maps-archive-hielke.md)
- [Maps by community creators](hielke-maps-archive-community.md)
- [Download ZIP snapshots](https://github.com/GammelSami/hielkemaps-archive/releases)
- [Update instructions](doku.md)
- [Latest completeness audit](archive-audit.json)
- [Archive.org capture status](wayback-status.json)

ZIP snapshots are distributed as GitHub release assets, outside Git history.
The tables show the latest stored snapshot for each detected Minecraft version;
additional snapshots of the same version remain available in the releases.
Minecraft versions are read from `level.dat` and do not guarantee compatibility.

The archive covers publicly linked Java map ZIPs and accompanying resource packs.
Bedrock Marketplace products are not downloadable ZIPs in this collection.
Discovery checks the map listings, sitemap and individual map pages.
Wayback captures are tracked separately: a GitHub upload does not prove that
Archive.org has saved the same file, and failed save requests remain incomplete.

Source and creator information: [hielkemaps.com](https://hielkemaps.com/).
Maps and images remain the property of their respective creators.
